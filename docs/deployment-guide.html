二、服务器初始化

2.1 连接服务器

ssh root@111.228.32.116

2.2 安装Docker（国内服务器）

注意：国内服务器使用官方源经常超时，建议使用阿里云镜像源 
# 方式一：使用阿里云镜像源安装（推荐）
curl -fsSL https://get.docker.com | bash -s docker --mirror Aliyun

# 方式二：手动安装
apt-get update
apt-get install -y apt-transport-https ca-certificates curl software-properties-common
curl -fsSL https://mirrors.aliyun.com/docker-ce/linux/ubuntu/gpg | apt-key add -
add-apt-repository "deb [arch=amd64] https://mirrors.aliyun.com/docker-ce/linux/ubuntu $(lsb_release -cs) stable"
apt-get update
apt-get install -y docker-ce docker-ce-cli containerd.io

三、项目部署

3.1 创建项目目录

# 创建部署目录
mkdir -p /root/baby-feeding
cd /root/baby-feeding

3.2 上传项目文件

# 在本地执行，打包项目（排除不需要的文件）
cd /path/to/babyFeedingReminder
tar --exclude='./ios' \
    --exclude='./node_modules' \
    --exclude='./.git' \
    --exclude='./backend/target' \
    -czvf baby-feeding.tar.gz .

# 上传到服务器
scp baby-feeding.tar.gz root@111.228.32.116:/root/baby-feeding/

# 在服务器上解压
cd /root/baby-feeding
tar -xzvf baby-feeding.tar.gz

3.3 创建环境配置文件

# 创建 .env 文件
cat > .env << 'EOF'
# MySQL配置
MYSQL_ROOT_PASSWORD=YourStrongPassword123!

# JWT密钥（建议生成随机字符串）
JWT_SECRET=YourRandomJWTSecretKey2025VerySecure

# 环境标识
SPRING_PROFILES_ACTIVE=prod
EOF

# 设置权限（仅root可读）
chmod 600 .env
安全提醒：请修改默认密码！生产环境切勿使用示例中的弱密码。

3.4 简化docker-compose.yml（轻量服务器）

注意：如果服务器内核不支持 CPU CFS 调度器（如轻量级虚拟机），需要移除资源限制配置。 
# 创建简化版 docker-compose.yml
cat > docker-compose.yml << 'EOF'
services:
  mysql:
    image: mysql:8.0
    container_name: baby-feeding-mysql
    ports:
      - "3306:3306"
    command: --character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci
    environment:
      - MYSQL_ROOT_PASSWORD=${MYSQL_ROOT_PASSWORD:-root123}
      - MYSQL_DATABASE=baby_feeding
    volumes:
      - mysql_data:/var/lib/mysql
      - ./backend/src/main/resources/db/init.sql:/docker-entrypoint-initdb.d/init.sql
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "localhost"]
      timeout: 20s
      retries: 10
    networks:
      - baby-network
    restart: unless-stopped

  redis:
    image: redis:7-alpine
    container_name: baby-feeding-redis
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data
    networks:
      - baby-network
    restart: unless-stopped

  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    container_name: baby-feeding-backend
    ports:
      - "8080:8080"
    environment:
      - SPRING_PROFILES_ACTIVE=prod
      - SPRING_DATASOURCE_URL=jdbc:mysql://mysql:3306/baby_feeding?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true
      - SPRING_DATASOURCE_USERNAME=root
      - SPRING_DATASOURCE_PASSWORD=${MYSQL_ROOT_PASSWORD:-root123}
      - SPRING_REDIS_HOST=redis
      - SPRING_REDIS_PORT=6379
    depends_on:
      mysql:
        condition: service_healthy
      redis:
        condition: service_started
    networks:
      - baby-network
    restart: unless-stopped

networks:
  baby-network:
    driver: bridge

volumes:
  mysql_data:
  redis_data:
EOF

3.5 优化Dockerfile（加速构建）

# 编辑 backend/Dockerfile
cat > backend/Dockerfile << 'EOF'
# 使用预装Maven的镜像加速构建
FROM maven:3.9-eclipse-temurin-17-alpine AS builder

WORKDIR /app

# 配置阿里云Maven镜像
RUN mkdir -p /root/.m2 && \
    echo '' > /root/.m2/settings.xml && \
    echo '' >> /root/.m2/settings.xml && \
    echo 'aliyun*' >> /root/.m2/settings.xml && \
    echo 'https://maven.aliyun.com/repository/public' >> /root/.m2/settings.xml && \
    echo '' >> /root/.m2/settings.xml

# 先复制pom.xml下载依赖（利用Docker缓存）
COPY pom.xml .
RUN mvn dependency:go-offline -B || true

# 再复制源码编译
COPY src ./src
RUN mvn clean package -DskipTests

# 运行阶段
FROM eclipse-temurin:17-jre-alpine
WORKDIR /app
RUN addgroup -S appgroup && adduser -S appuser -G appgroup
COPY --from=builder /app/target/*.jar app.jar
RUN chown -R appuser:appgroup /app
USER appuser
EXPOSE 8080
ENV JAVA_OPTS="-Xms256m -Xmx512m -XX:+UseG1GC"
ENTRYPOINT ["sh", "-c", "java $JAVA_OPTS -jar app.jar"]
EOF

5.2 日志关键信息解读

正常启动日志示例： 
Started BabyFeedingReminderApplication in 8.234 seconds
常见错误日志：
  • Connection refused: redis:6379 - Redis未启动或网络不通
  • Access denied for user 'root' - MySQL密码错误
  • Table 'baby_feeding.xxx' doesn't exist - 数据库表未初始化

5.3 导出日志到文件

# 按日期保存日志

九、故障排查

9.1 常见问题速查表

问题可能原因解决方案
容器启动失败 端口被占用 lsof -i :8080 查找并终止占用进程
NanoCPUs错误 内核不支持CFS调度器 移除docker-compose.yml中的cpus配置
镜像拉取超时 网络问题 配置Docker镜像加速器
Redis连接失败 配置错误 检查SPRING_REDIS_HOST环境变量是否为redis
数据库连接失败 MySQL未就绪 检查MySQL健康状态，等待初始化完成

9.2 排查流程

# 1. 检查容器状态
docker compose ps

# 2. 查看错误日志
docker compose logs --tail 50 backend

# 3. 检查网络连通性
docker exec baby-feeding-backend ping -c 3 mysql
docker exec baby-feeding-backend ping -c 3 redis

# 4. 检查端口监听
docker exec baby-feeding-backend nc -zv redis 6379
docker exec baby-feeding-backend nc -zv mysql 3306

# 5. 检查环境变量
docker exec baby-feeding-backend env | grep SPRING
